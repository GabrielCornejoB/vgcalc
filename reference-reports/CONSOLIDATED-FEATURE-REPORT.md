## TL;DR for a Champions-only (Mega-only) VGC calc

- **Damage math: use `damage-calc/calc/` (`champions.ts` + `util.ts` + `stats.ts` + `desc.ts`), cross-checked against `NCP/script_res/damage_SV.js + damage_MASTER.js + ko_chance.js + stat_data.js`.** Both implement a Champions ruleset; `damage-calc` is the cleaner, tested, API-able one; NCP is the VGC-UX reference (doubles default, sidebars, curated sets).
- **Data: use `ps/dex + data` (`Dex.forGen/mod`, `Generations.get`, `Stats.calc`, `Types.totalEffectiveness`) layered with the `ps/mods/src/champions*` overlay as the canonical Champions content source**, then project into whichever calc-table shape you keep (`damage-calc` `CHAMPIONS_PATCH` or NCP `POKEDEX_CHAMPIONS` globals).
- **Mega Evolution is the only gimmick to keep.** All three capable projects support it via data (`megaStone` map / `MEGA_STONE_USER_LOOKUP` / `scripts.ts:canMegaEvo`), not via a damage-stage rewrite — so you can drop all Z/Max/Tera/Stellar/Ruin/QP branches and keep only Mega forme + Mega-Stone item logic.
- **Ignore `engine/` for product code** (gen1–2 only, no doubles, no Champions, no calc UI — only `base/final/capped` summaries as a data feed: `engine/src/lib/gen1/calc.zig:37-134`).
- **Relational shape: copy `pokeapi/`'s schema, fill it with calc/ps content.** PokeAPI splits `pokemon_species` (shared: genera, egg groups, gender_rate, evolution chain, varieties) vs `pokemon` (per-variety battle row: stats, abilities, moves, types, items — Megas, gender and regional variants are separate `pokemon` rows, e.g. `venusaur-mega` 10033, `indeedee-female` 10186, `arcanine-hisui` 10230) vs `pokemon_forms` (`is_default/is_battle_only/is_mega/form_order` + trigger/item/ability/move conditions). Version-group scoping (moves, learners, machines, past values keyed by version group) is the ready-made analogue of per-regulation legality/overrides.
- **PokeAPI caveats:** no damage math anywhere; main-series data (a version group literally named `champions`, id 32, gen 9 exists in `data/v2/csv/version_groups.csv` — verify whether it carries Champions-game content before relying on it); Mega battle rules live in `ps` mods, not here; ignore encounters/contests/pal-park/pokeathlon/GraphQL/cache/deploy surfaces.
